### Конспект лекции: Обратная матрица, Ранг матрицы, Системы линейных уравнений

---

#### 1. **Обратная матрица (А⁻¹)**

**Определение:**  
Обратная матрица `A⁻¹` для квадратной матрицы `A` существует, если выполняется условие:  
`A * A⁻¹ = A⁻¹ * A = E`  
где `E` — единичная матрица.

- Обратная матрица имеет ту же размерность, что и исходная (`A` порядка `n`).
    
- Если определитель матрицы `A` равен нулю (`det(A) = 0`), матрица называется **вырожденной**, и обратной матрицы для нее не существует.
    
- `det(A⁻¹) = 1 / det(A)`
    

**Способы нахождения:**

1. **Через алгебраические дополнения (формула):**  
    `A⁻¹ = (1 / det(A)) * Āᵀ`  
    где `Ā` — матрица алгебраических дополнений элементов исходной матрицы `A`.
    
    - _Недостаток:_ Трудоемкий для матриц высокого порядка (нужно вычислить много определителей).
        
2. **Метод элементарных преобразований (Гаусса-Жордана):**
    
    - Записываем блочную матрицу `[A | E]`.
        
    - С помощью элементарных преобразований **только над строками** приводим левый блок к единичному виду `[E | B]`.
        
    - Тогда матрица `B` в правом блоке и будет искомой обратной матрицей `A⁻¹`.

#### 2. **Ранг матрицы**

**Определения:**

- **Минор** порядка `k` — определитель матрицы, образованной элементами, стоящими на пересечении `k` строк и `k` столбцов исходной матрицы.
    
- **Ранг матрицы** — наибольший порядок минора, не равного нулю.  
    `rang(A) = r`
    
- **Базисный минор** — любой ненулевой минор порядка `r` (равного рангу матрицы).
    

**Свойства ранга:**

- Ранг не меняется при транспонировании.
    
- Ранг не меняется при элементарных преобразованиях строк (или столбцов).
    
- Ранг произведения матриц не превосходит ранга каждого из сомножителей.
    
- При вычеркивании нулевой строки/столбца ранг не меняется.
    

**Способы нахождения:**

- **Метод окаймляющих миноров:** Перебор миноров от низших порядков к высшим. _Недостаток:_ очень трудоемко.
    
- **Метод элементарных преобразований:** Привести матрицу к ступенчатому (треугольному) виду. Количество ненулевых строк в ступенчатой форме и будет рангом матрицы. _Это наиболее практичный способ._
    

**Эквивалентное определение:**  
Ранг матрицы — это максимальное число ее линейно независимых строк (или столбцов). Строки `a₁, a₂, ..., aₘ` линейно независимы, если равенство `λ₁a₁ + λ₂a₂ + ... + λₘaₘ = 0` возможно только при `λ₁ = λ₂ = ... = λₘ = 0`.

#### 3. **Системы линейных алгебраических уравнений (СЛАУ)**

**Общий вид:**  
Система `m` уравнений с `n` неизвестными.

**Матричная форма записи:**  
`A * X = B`  
где:

- `A` — матрица коэффициентов системы (размер `m x n`)
    
- `X` — столбец неизвестных
    
- `B` — столбец свободных членов
    

**Расширенная матрица системы:**  
Матрица `[A | B]`, к которой справа дописан столбец `B`.

**Классификация решений:**

1. **Совместная система:** Имеет хотя бы одно решение.
    
    - **Определенная:** Имеет ровно одно решение.
        
    - **Неопределенная:** Имеет бесконечно много решений.
        
2. **Несовместная система:** Не имеет решений.
    

**Однородная система:** `A * X = 0`. Всегда совместна (имеет нулевое решение).

---

#### 4. **Теорема Кронекера-Капелли**

**Формулировка:**  
Система совместна **тогда и только тогда**, когда ранг матрицы системы равен рангу расширенной матрицы:  
`rang(A) = rang([A | B])`

**Следствия:**

- Если `rang(A) = rang([A | B]) = n` (числу неизвестных), то система **определена** (имеет единственное решение).
    
- Если `rang(A) = rang([A | B]) = r < n`, то система **неопределена** (имеет бесконечно много решений).
    

---

#### 5. **Методы решения СЛАУ**

1. **Матричный метод:**
    
    - _Применим только_ когда `m = n` и `det(A) ≠ 0`.
        
    - Решение находится по формуле: `X = A⁻¹ * B`
        
    - _Недостаток:_ Необходимость вычислять обратную матрицу, что трудоемко.
        
2. **Метод Крамера:**
    
    - _Применим только_ когда `m = n` и `det(A) ≠ 0`.
        
    - Решение находится по формулам: `xᵢ = Δᵢ / Δ`  
        где `Δ` — главный определитель (det(A)), а `Δᵢ` — определитель, полученный заменой `i`-го столбца в `A` на столбец `B`.
        
    - _Недостаток:_ Трудоемкость вычисления определителей высокого порядка.
        
3. **Метод Гаусса (последовательного исключения неизвестных):**
    
    - **Универсальный метод.** Применим к любой системе.
        
    - **Прямой ход:** С помощью элементарных преобразований **над строками** расширенная матрица `[A | B]` приводится к **ступенчатому (треугольному)** виду.
        
    - **Обратный ход:** Неизвестные последовательно находятся, начиная с последнего уравнения преобразованной системы.
        
    
    **Анализ результата прямого хода:**
    
    - **Единственное решение:** В ступенчатом виде число ненулевых строк равно числу неизвестных.
        
    - **Нет решений:** Если получилась строка вида `[0 0 ... 0 | b]`, где `b ≠ 0`.
        
    - **Бесконечно много решений:** Если число ненулевых строк меньше числа неизвестных. Часть переменных объявляется свободными (параметрами), а остальные (базисные) выражаются через них.
