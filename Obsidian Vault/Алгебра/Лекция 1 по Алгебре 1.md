### Сводка лекции: Основы матричного исчисления и определителей

Лекция посвящена введению в основные понятия линейной алгебры: матрицы, операции над ними и определители.

---

#### **Часть 1: Матрицы**

**1. Определение и основные понятия:**

- **Матрица** — прямоугольная таблица чисел, упорядоченная по строкам и столбцам.
    
- **Размерность:** Обозначается как `m × n`, где `m` — число строк, `n` — число столбцов.
    
- **Элемент матрицы:** `a_ij`, где `i` — номер строки, `j` — номер столбца.
    
- **Главная диагональ:** Элементы, у которых номер строки совпадает с номером столбца (`a_11, a_22, ..., a_nn`).
    

**2. Типы матриц:**

- **Матрица-строка:** `m = 1`.
    
- **Матрица-столбец:** `n = 1`.
    
- **Квадратная матрица:** `m = n` (порядка `n`).
    
- **Нулевая матрица:** Все элементы равны 0.
    
- **Диагональная матрица:** Ненулевые элементы только на главной диагонали.
    
- **Скалярная матрица:** Диагональная матрица, где все элементы на главной диагонали равны.
    
- **Единичная матрица (`E` или `I`):** Скалярная матрица, где элементы на главной диагонали равны 1. Выполняет роль "единицы" при умножении.
    
- **Симметричная матрица:** `a_ij = a_ji` (матрица равна своей транспонированной).
    
- **Верхняя треугольная матрица:** Все элементы ниже главной диагонали равны 0.
    
- **Нижняя треугольная матрица:** Все элементы выше главной диагонали равны 0.
    

**3. Операции над матрицами:**

- **Сложение и вычитание:** Определены только для матриц одинаковой размерности. Выполняются поэлементно.
    
- **Умножение на число:** Каждый элемент матрицы умножается на это число.
    
- **Транспонирование:** Операция, при которой строки матрицы становятся столбцами, а столбцы — строками. Обозначается `A^T`.
    
- **Умножение матриц:** Самая сложная операция.
    
    - **Условие:** Умножать можно только матрицы `A` (размер `m × k`) и `B` (размер `k × n`). Число столбцов первой матрицы должно равняться числу строк второй.
        
    - **Результат:** Матрица `C` размером `m × n`.
        
    - **Формула элемента:** Элемент `c_ij` матрицы `C` равен сумме попарных произведений элементов `i`-й строки матрицы `A` на соответствующие элементы `j`-го столбца матрицы `B`.
    - ### Объяснение на пальцах

Представьте, что у вас есть две матрицы: `A` и `B`. Вы хотите их перемножить, чтобы получить новую матрицу `C`.

**Правило:** Чтобы найти элемент, который стоит в `i`-ой строке и `j`-ом столбце результата (то есть элемент `c_ij`), вам нужно:

1. Взять **всю `i`-ую строку** из первой матрицы (`A`).
    
2. Взять **весь `j`-ый столбец** из второй матрицы (`B`).
    
3. **Попарно перемножить** их элементы: первый элемент строки на первый элемент столбца, второй на второй, третий на третий и так далее.
    
4. **Сложить** все получившиеся произведения.
    

---

### Наглядный пример "Правила "Строка на Столбец""

Допустим, мы умножаем матрицу `A` на матрицу `B`:

text

      Матрица A (2x3)      Матрица B (3x2)
      | 1  2  3 |          | 7  8 |
      | 4  5  6 |          | 9  0 |
                           | 1  2 |

Мы хотим найти элемент `c_11` — тот, что будет стоять в **первой строке** и **первом столбце** результата.

1. **Берём первую строку из A:** `[1, 2, 3]`
    
2. **Берём первый столбец из B:** `[7, 9, 1]` (обратите внимание: мы смотрим именно на столбец сверху вниз)
    
3. **Попарно перемножаем** и **складываем:**  
    `c_11 = (1 * 7) + (2 * 9) + (3 * 1) = 7 + 18 + 3 = 28`
    

**Отлично! Мы нашли первый элемент.** Теперь давайте найдём, например, элемент `c_22` — во **второй строке** и **втором столбце** результата.

1. **Берём вторую строку из A:** `[4, 5, 6]`
    
2. **Берём второй столбец из B:** `[8, 0, 2]`
    
3. **Попарно перемножаем** и **складываем:**  
    `c_22 = (4 * 8) + (5 * 0) + (6 * 2) = 32 + 0 + 12 = 44`
    

### Визуализация процесса

Давайте представим этот процесс графически для элемента `c_ij`. Двигайте строку `A` вниз, пока она не "встанет" на столбец `B`,就像 пазл:

text

Чтобы найти C[i][j]:

|Шаг|Визуализация|Расчет|
|---|---|---|
|**1.** Берём **i**-ю строку из первой матрицы|`A = [ ... , a_i1, a_i2, ..., a_in, ... ]`||
|**2.** Берём **j**-й столбец из второй матрицы|<code>B = [ ..., b_1j, ... ]  <br>    [ ..., b_2j, ... ]  <br>    [ ..., ..., ... ]  <br>    [ ..., b_nj, ... ]</code>||
|**3.** Умножаем и складываем "как пазл"|`(a_i1 * b_1j) + (a_i2 * b_2j) + ... + (a_in * b_nj)`|`= c_ij`|

Проделав эту операцию для _каждой_ комбинации строки `A` и столбца `B`, мы получим итоговую матрицу `C` размером `2x2`:

### Главное правило, которое нужно запомнить:

**КАЖДАЯ СТРОКА первой матрицы "обходит" КАЖДЫЙ СТОЛБЕЦ второй матрицы, чтобы занять свою ячейку в результате.**

Это механическая работа. Нужно просто быть внимательным и не пропустить ни один элемент в строке и столбце.
        
    - **Важно:** Умножение некоммутативно (`A × B ≠ B × A` в общем случае). Существуют _делители нуля_ (ненулевые матрицы, произведение которых дает нулевую матрицу).
        

**4. Свойства операций:**

- Коммутативность и ассоциативность сложения.
- **Формулировка:** Результат сложения не зависит от того, как мы сгруппируем слагаемые. То есть, как мы расставим скобки.
**Для матриц это означает:** Если вам нужно сложить три матрицы, вы можете сначала сложить первые две, а потом прибавить третью. Или можно сначала сложить вторую и третью, а потом прибавить первую. Результат будет одинаков.
- **Формулировка:** От перемены мест слагаемых сумма не меняется.

**Для матриц это означает:** Порядок, в котором вы складываете матрицы, не важен. Вы можете написать `A + B` или `B + A` — результат будет одинаковым.
    
- Дистрибутивность умножения относительно сложения.
    
- `(A × B)^T = B^T × A^T`
    
- `A × E = E × A = A`
    

**5. Элементарные преобразования матриц:**  
Преобразования, не меняющие фундаментальных свойств матрицы (используются для решения систем уравнений, нахождения ранга):

1. Перестановка местами двух строк (столбцов).
    
2. Умножение всех элементов строки (столбца) на число, не равное нулю.
    
3. Прибавление к элементам одной строки (столбца) соответствующих элементов другой строки (столбца), умноженных на число.
    
4. Вычеркивание нулевой строки (столбца).
    

С помощью этих преобразований матрицу можно привести к _ступенчатому_ или _трапециевидному_ виду.

#### **Часть 2: Определители (Детерминанты)**

**1. Определение:**

- **Определитель** — это число, которое ставится в соответствие _квадратной_ матрице.
    
- **Обозначение:** `det(A)`, `|A|` или просто черточки вокруг элементов.
    

**2. Вычисление для малых порядков:**

- **Порядок 1:** `det([a]) = a`
    
- **Порядок 2:**
    
    text
    
    |a b|
    |c d| = a*d - b*c
    
- **Порядок 3 (Правило треугольников или Саррюса):**
    
    text
    
    |a b c|
    |d e f| = a*e*i + b*f*g + c*d*h - c*e*g - b*d*i - a*f*h
    |g h i|
    

**3. Свойства определителей:**

1. Определитель не меняется при транспонировании (`det(A) = det(A^T)`).
    
2. При перестановке двух строк (столбцов) определитель меняет знак.
    
3. Определитель с двумя одинаковыми строками (столбцами) равен нулю.
    
4. Общий множитель всех элементов строки (столбца) можно вынести за знак определителя.
    
5. Определитель с нулевой строкой (столбцом) равен нулю.
    
6. Если строки (столбцы) пропорциональны, определитель равен нулю.
    
7. Определитель не изменится, если к элементам одной строки (столбца) прибавить соответствующие элементы другой строки (столбца), умноженные на число. **Это ключевое свойство для вычисления.**
    
8. Определитель произведения матриц равен произведению их определителей (`det(A × B) = det(A) × det(B)`).
    

**4. Методы вычисления (для порядков > 3):**

- **Метод эффективного вычисления:** С помощью элементарных преобразований (в основном, св-во №7) получить как можно больше нулей в строке или столбце, а затем разложить по этой строке/столбцу.
    
- **Разложение по строке/столбцу (Теорема Лапласа):**
    
    - **Минор `M_ij`** — определитель матрицы, полученной из исходной вычеркиванием `i`-й строки и `j`-го столбца.
        
    - **Алгебраическое дополнение `A_ij`:** `A_ij = (-1)^(i+j) * M_ij`
        
    - **Формула разложения:** Определитель равен сумме произведений элементов _любой_ строки (или столбца) на их алгебраические дополнения.
        
    - `det(A) = a_i1 * A_i1 + a_i2 * A_i2 + ... + a_in * A_in` (разложение по `i`-й строке).
