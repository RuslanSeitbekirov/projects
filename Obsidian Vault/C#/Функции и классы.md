Модификатор  Static говорит программе что поле доступно всем без создания классового объекта. (Robot.count = 34). Значение поля с модификатором static сохраняется и доступно всем классовым объектам. 

Ключевое слово this используется что бы компилятор отличал переменные которые приходят в метод от своих полей.
Пример:
```
        public void setValues(string name, int weight, byte[] coordinates)

        {

            this.name = name;

            this.weight = weight;

            this.coordinates = coordinates;

        }
```

Используется так же для того чтобы явно обозначить что используется метод расположенный внутри класса (представите что есть два разных класс у которых есть метод setValue, который оба используют, this.setValue говорит компилятору "Используй мой метод")

## Операторы is и as


is -  is проверяет создан ли объект на основе класса/типа данных
```
System.Console.WriteLine(obj is Robot);

Вывод: True если Robot obj и для всех наследников класса Robot
	   False если остальное 
```

as -  as преобразует объект класса А в объект класса Б 
```
Robot newRobot = null;
newRobot = obj as Robot; 
```
