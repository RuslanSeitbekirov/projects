Конвертация через  метод Convet
```
- ToBoolean: делает тип `bool` из чисел или строк.
- ToChar: меняет данные на символ `char`.
- ToByte / ToSByte**: переводит в целое число от 0 до 255 или от -128 до 127.
- ToInt16 / ToUInt16**: создает короткое целое число.
- ToInt32 / ToUInt32**: делает обычное целое число (`int`).
- ToInt64 / ToUInt64**: делает длинное целое число (`long`).
- ToSingle: переводит в дробное число с плавающей точкой (`float`).
- ToDouble: переводит в дробное число удвоенной точности (`double`).
- ToDecimal: делает точное финансовое число (`decimal`).
- ToDateTime: преобразует текст в дату и время `DateTime`.
- ToString: делает текст из любого базового типа.
```

Пример:
```
System.Console.Write("Write first num:");
a = Convert.ToInt32(Console.ReadLine());
```

Взаимодействие с массивом

```
numb.Add(0);
numb.Add(100);
numb.Add(200);
numb.Add(300);
numb.Remove(100); // указываем не индекс, а элемент

numb.Reverse(); // Sort по убыванию
foreach (int item in numb)

	System.Console.WriteLine(item);
```
