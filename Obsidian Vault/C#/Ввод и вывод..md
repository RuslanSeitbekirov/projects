

Функции ввода:

- Console.ReadLine: считывает всю введенную строку с клавиатуры до нажатия Enter.

- Console.ReadKey: Считывает **одно мгновенное нажатие клавиши**. Программа реагирует сразу, нажимать Enter не нужно. Возвращает специальный объект-структуру `ConsoleKeyInfo`. Он содержит информацию о нажатой клавише, её символ, а также состояние системных клавиш (Shift, Ctrl, Alt).

- Console.Read(): берёт первый символ после нажатия Enter и возвращает данные типа `int` — числовой **ASCII / Unicode код** этого символа. Если символов больше нет, возвращает `-1`
- Пример: string name = Console.ReadLine();

Функции вывода:

- Console.Write: выводит текст на экран, курсор остается на той же строке.
- Console.WriteLine: выводит текст и переводит курсор на новую строку.
- Пример: Console.WriteLine("Привет мир!");
(есть сокращение cw которое вводит System.Console.WriteLine();)
